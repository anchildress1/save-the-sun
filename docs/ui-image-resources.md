## Voice medallion level strip (S3 / R6)

| | |
|---|---|
| File | `src/lib/assets-webp/ui/voice-medallion-levels.webp` |
| Status | **Live (volume-levels-12, 128px)** — `EclipseMedallion.svelte` renders it as the `.disc` layer |
| Strip | 1536×128: 12 frames of 128px laid out horizontally, glow intensity 0 (rest) → 11 (peak), opaque dark background, 43K |
| Authoring | Monotonic intensity ramp; the manifest's mapping `level = min(11, floor(volume01 * 12))` is implemented verbatim by `spriteLevel()` in `medallionState.ts`. |
| Playback | Static level per state (denied 0, idle/thinking rest 4, recording/speaking/Sköll peak 11); recording/speaking/Sköll ping-pong the ramp through one `steps(12, jump-none)` + `alternate` keyframes ramp (two speeds). Reduced motion freezes on the static level. |
| Sköll | Same strip, `hue-rotate`/`saturate` ember tint — always paired with the deepening-eclipse shape signal (the disc darkens toward total eclipse with an ember rim). |
| Regenerate | Export a new 12-frame 128px strip and drop it in place (the source pipeline already emits webp). A different level count means updating `SPRITE_LEVELS` and the CSS step count together. |
| Source | Generated by Ashley's pipeline; working files were temporary and not retained — re-export to change. |

The rim runes are **not** part of this asset: they reuse `src/lib/assets-webp/runes/*.webp`
via CSS transforms (`RING_RUNES` in `medallionState.ts`); the mic glyph stays a CSS
layer on top. The eclipse itself lives in the artwork — the Sköll-speaking state deepens it via CSS.
